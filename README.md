# Claude Executive Labs

The participant page for the three hands-on labs in Day 2 of
**Claude for Business**, Tuwaiq Academy.

One file, `index.html`. No build step, no dependencies.
It is served by GitHub Pages so the QR code opens a browser on any phone —
a `claude.ai` link is claimed by the Claude app and opens that instead.

To change the Executive Update link, edit the one line near the bottom of
`index.html` that begins `var EXECUTIVE_UPDATE_URL`.
